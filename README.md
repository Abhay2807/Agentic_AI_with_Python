# Agentic AI with Python

A hands-on Python codebase and learning playground for building **Agentic AI** systems from the ground up. It progresses step by step from Python fundamentals and LLM API usage to Retrieval-Augmented Generation (RAG), Vector Databases, autonomous tool-using agents, and containerized deployment with Docker.

---

## What This Repo Covers

1. **Basics of AI** — Core concepts behind machine learning, deep learning, foundation models, and how traditional software differs from probabilistic, goal-driven agentic workflows.
2. **API Key Usage & Security** — Managing provider credentials safely with `.env` files, `python-dotenv`, environment validation, and `.gitignore` hygiene.
3. **Python Core Concepts** — Practical Python patterns used across AI engineering: virtual environments, type hints, `async`/`await`, context managers, `dataclasses`, and `Pydantic` schemas.
4. **LLMs (Large Language Models)** — Tokenisation, context windows, temperature/sampling, prompt engineering, structured outputs, and tool/function calling.
5. **Basics of RAG (Retrieval-Augmented Generation)** — Document loading, text chunking strategies, embedding generation, hybrid/semantic retrieval, and grounded response synthesis.
6. **Vector Databases** — Storing embeddings, similarity metrics (cosine, dot product, L2), metadata filtering, and local vs. hosted vector stores.
7. **Agentic AI Workflows** — ReAct loops, multi-step planning, tool execution, memory (short-term/working vs. persistent), guardrails, and human-in-the-loop checkpoints.
8. **Docker Usage** — Reproducible Python environments, multi-stage `Dockerfile`s, `.dockerignore`, and running agents with environment variables via Docker / Compose.
